# TO-DO List — Gestionnaire de tâches

## Présentation

TO-DO List est une application web qui permet de gérer ses tâches quotidiennes simplement.

## Fonctionnalités

- Ajouter une tâche
- Supprimer une tâche
- Marquer une tâche comme terminée
- Réactiver une tâche terminée
- Filtrer les tâches : toutes, en cours et terminées
- Afficher le nombre de tâches restantes
- Conserver les tâches après actualisation de la page grâce à localStorage

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git et GitHub

## Installation et utilisation

1. Cloner ce dépôt GitHub.
2. Ouvrir le fichier `index.html` dans un navigateur.
3. Ajouter et gérer ses tâches.
